## What's Changed

### 修复

- 修复 Star Context 类型定义，恢复相关 SDK 类型提示。
- 延迟加载 FAISS C 扩展，降低部分环境启动阶段卡住的风险。
- 关闭核心生命周期时释放主数据库引擎连接池。
- 文件夹创建弹窗支持按 Enter 提交，并在创建中禁用表单以减少重复提交。
- 修复 QQ 官方 Webhook 重启路径和签名校验相关问题。
- 修复插件重装/更新时仓库来源匹配不稳定的问题。
- 修复群聊上下文中引用回复内容缺失的问题。

### 优化

- 现实时间系统提示现在同时包含星期信息。
- 备份导出/导入范围包含 Skills 目录，并同步 Dashboard 说明文案。
- `send_message_to_user` 对本地运行时的任意主机文件路径使用增加权限限制，降低误发本机文件的风险。
- Dashboard 函数工具列表支持为非内置工具配置管理员权限。
- 新增 ElevenLabs TTS API Provider。
- 修正 LM Studio Docker 文档措辞，同步 Codecov Action v7 和少量 Python 语法清理。

## What's Changed (EN)

### Bug Fixes

- Fixed Star Context typing to restore related SDK type hints.
- Deferred FAISS C extension loading to reduce startup hangs in affected environments.
- Disposed the main database engine pool during core shutdown.
- Folder creation dialogs can now submit with Enter and disable the form while creating to reduce duplicate submissions.
- Fixed QQ Official Webhook restart-path and signature-verification behavior.
- Fixed unstable repository-source matching during plugin reinstall/update.
- Fixed missing quoted reply content in group chat context.

### Improvements

- Datetime system reminders now include weekday information.
- Backup export/import now includes the Skills directory, with Dashboard copy updated accordingly.
- `send_message_to_user` now restricts arbitrary host file paths in local runtime for non-admin callers.
- Dashboard function-tool management can configure admin-only permissions for non-builtin tools.
- Added the ElevenLabs TTS API provider.
- Fixed LM Studio Docker docs wording, updated Codecov Action to v7, and absorbed small Python syntax cleanups.
