## What's Changed

### 修复

- 修复钉钉 Stream 任务异常退出后无法持续重连的问题，提升钉钉适配器长连接稳定性。
- Dashboard 登录表单添加 `autocomplete` 属性，便于浏览器记住密码。

### 优化与工程

- 新增 `/name` 命令，用于为 UMO 命名并在 UI 中展示。

<a id="english"></a>

## What's Changed (EN)

### Bug Fixes

- Fixed DingTalk Stream task recovery so the adapter keeps reconnecting after unexpected SDK task exits.
- Added `autocomplete` attributes to the Dashboard login form for credential manager support.

### Improvements

- Added `/name` command for naming UMO entries shown in the UI.
