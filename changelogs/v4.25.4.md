## What's Changed

### 修复

- 修复 Pipeline 异步任务可能因缺少强引用而被垃圾回收的问题，提升事件处理稳定性。
- 修复 WebChat 使用 Web 搜索工具时，引用提示词在同一轮对话多次工具调用后被重复追加到系统消息的问题。
- 修复 Anthropic 内容过滤响应缺少 usage 时可能导致的兼容性问题。

### 优化

- 将个人微信 HTTP API 请求超时时间从 15 秒提升到 120 秒，降低较慢网络或接口响应下的超时失败概率。

<a id="english"></a>

## What's Changed (EN)

### Bug Fixes

- Fixed Pipeline async tasks potentially being garbage-collected due to missing strong references.
- Fixed repeated Web search citation prompt appends in WebChat after multiple tool calls within the same interaction.
- Fixed Anthropic compatibility when content-filtered responses return no usage payload.

### Improvements

- Increased the personal WeChat HTTP API request timeout from 15 seconds to 120 seconds.
