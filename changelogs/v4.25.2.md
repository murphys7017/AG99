## What's Changed

### 优化

- 版本号同步至 `4.25.2`。
- 默认 LLM 上下文压缩提示词更强调“后续工作可无缝继续”，并要求记录已阅读文件、文档、代码和参考资料的路径与范围。
- 知识库上传 Markdown 文件时使用标题层级感知分块，减少跨章节切块带来的语义断裂。
- WebUI 未来任务页面支持手动立即执行任务，并允许未来任务不指定投递 session，由运行时使用内部 cron 会话执行。
- 首次使用提示补充最终用户许可协议链接，并新增俄语提示文件。

### 修复

- 修复 WebUI 录音上传后未正确进入输入框附件状态的问题，录音现在与普通 staged file 共用上传和清理路径。

<a id="english"></a>

## What's Changed (EN)

### Improvements

- Bumped the project version to `4.25.2`.
- The default LLM context-compression prompt now emphasizes seamless continuation and asks the model to list useful files, documents, code, and references it read.
- Markdown knowledge-base uploads now use heading-aware chunking to keep sections semantically grouped.
- The Future Tasks WebUI can manually run a task now, and tasks may omit the delivery session so the runtime uses an internal cron session.
- First-use notices now include the EULA link and a Russian notice file.

### Bug Fixes

- Fixed WebUI voice recording so uploaded recordings are staged in the chat input through the same attachment path as other files.
